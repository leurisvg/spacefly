# Web / mobile parity

The mobile app is a Flutter rewrite of the removed NativeScript app. Every web route has a screen; an empty "Mobile route" cell would be a screen that is not ported. The web routes and view-models below are the reference for what to port. Update this table in the same change as any new screen.

| Feature | Web route | Mobile route | View-model |
|---|---|---|---|
| Dashboard | `/` | `/` (tab: KPIs, income vs expenses, top categories, net worth, budgets, subscriptions, calendar, largest; "View all" links to Budgets, Subscriptions and the calendar) | `dashboard.vm.ts` |
| Transactions list | `/transactions` | `/transactions` (tab: search, filters, sort, 50 at a time, a button for a new transaction, CSV export through the share sheet, swipe to delete any row, a warning for a record of several parts; a long press opens the row menu: edit (or edit in Firefly when SpaceFly doesn't edit it), open in Firefly, delete; a row in another currency shows the original amount with the conversion under it) | `explorer.vm.ts` |
| Transaction detail | detail sheet over the list | `/transactions/:id` (with edit and delete; when SpaceFly doesn't edit it: edit in Firefly, back and delete) and a bottom sheet (the transactions behind a chart slice, a calendar day or a budget) | `tx-detail.vm.ts`, `tx-view.vm.ts` |
| New / edit transaction | `/transactions/new`, `/transactions/:id/edit` | same paths (the new form takes the same `?source=…&amount=…` pre-fill; a transaction that is not editable offers edit in Firefly, back and delete) | `transaction-form.vm.ts`, `account-picker.vm.ts` |
| Accounts | `/accounts` | `/accounts` (tab: balances, flow, balance history, a button to create an account, an edit button per account and a reorder mode with arrows and drag handles that saves itself, plus "reset order") | `accounts.vm.ts` |
| Settings | `/settings` | `/settings` (tab: theme, language, display currency, privacy, server and sign out, refresh data, open Firefly) | `preferences.vm.ts` |
| Login | `/login` | `/login` (it remembers where the user was in `?returnTo=` and leads back there after signing in), plus `/server` for the server URL and Cloudflare Access credentials | `login.vm.ts` |
| Drill into a chart slice | sheet / explorer filters | bottom sheet (`showDrillSheet`) | `explorer.vm.ts` |
| Monthly summary | `/reports/monthly` | `/reports/monthly` (from the More tab: KPIs, categories with change, daily cash flow, budgets, top 5, account activity, savings, overview; the Sankey is a link to Flow, with that screen) | `monthly.vm.ts` |
| Annual report | `/reports/annual` | `/reports/annual` (averages, best and worst month, income and expenses, savings rate, category × month matrix that scrolls sideways) | `annual.vm.ts` |
| Money flow | `/reports/flow` | `/reports/flow` (from the More tab and the monthly summary: vertical Sankey drawn natively that scrolls sideways when a layer is crowded, mode / budgets / income categories / small-flow threshold, legend, every link listed; tapping a node or a link opens its transactions) | `flow.vm.ts` |
| Calendar | `/reports/calendar` | `/reports/calendar` (month grid with account / category / tag filters, running balance, scheduled items; year heatmap drawn vertically) | `calendar.vm.ts` |
| Compare | `/reports/compare` | `/reports/compare` (previous / last year / custom B with a native range picker, grouping, kind, diverging bars, trend, table) | `compare.vm.ts` |
| Categories, tags, merchants, income sources | `/analysis/*` | `/analysis/categories`, `/analysis/tags`, `/analysis/merchants`, `/analysis/income-sources` (side switch, bars / treemap / budget sunburst, 12-month trend, list with change; a plus creates an entity and a row opens its editor) | `ranking.vm.ts` |
| Budgets | `/analysis/budgets` | `/analysis/budgets` (totals, a card per budget with the expected-pace tick and projection, history and categories of the picked one; a plus creates a budget and a card opens its editor) | `budgets.vm.ts` |
| Account detail, net worth, savings, counterparties | `/accounts/:id`, `/accounts/net-worth`, `/accounts/savings`, `/accounts/{expense,revenue}` and `/accounts/{expense,revenue}/:id` | same paths, full screens over the tabs (opened from a card of the Accounts tab and from the More tab). The account detail opens on the last 30 days and hands the user's period back; a foreign account is drawn in its own currency with what it is worth next to it; the net worth stacks the positive balances | `account-detail.vm.ts`, `net-worth.vm.ts`, `savings.vm.ts`, `counterparties.vm.ts`, `counterparty-detail.vm.ts` |
| Subscriptions, recurring, goals, projection | `/planning/bills`, `/planning/recurring`, `/planning/goals`, `/planning/projection` | same paths (from the More tab: subscriptions and goals have a plus and open their editor, a subscription opens its transactions; recurring transactions are read-only; the projection has day-horizon chips, the lowest point and the scheduled events) | `bills.vm.ts`, `recurring.vm.ts`, `goals.vm.ts`, `projection.vm.ts` |
| Entity editors (category, tag, budget, subscription, account, goal) | side sheet | `/edit/:kind` and `/edit/:kind/:id` (a full screen; "Create" section of the More tab, a plus and an edit button in Categories, Tags, Merchants, Income sources, Budgets and Accounts; deleting an account asks to type its name) | `entity-form.vm.ts` and one `*-form.vm.ts` per entity |
| Server settings (excluded accounts, balance window, Sankey threshold, rates in use) | section of `/settings` | `/settings/server` | `settings.vm.ts` |
| Exchange rates (add, replace, delete) | section of `/settings` | `/settings/exchange-rates` | `exchange-rates.vm.ts` |
| CSV export | transactions list | transactions list (app bar button; the CSV goes to the share sheet and is disabled while amounts are hidden) | `explorer.vm.ts` |
| View options in the URL | `?p=&start=&end=&cur=` and each screen's own (`mode`, `threshold`, `view`, `kind`, `months`, `days`, `budget`, `tab`, `cmp`, `groupBy`, `bStart`, `bEnd`, `account`, `category`, `tag`…), read with `filters.param(…)` and written with `setParams` | Same names, read once per location from the link by `applyRouteParams` (`lib/features/route_params.dart`, called from the router's redirect) into the screen's own state, which lives for the session instead of dying with the screen. An invalid value is ignored and what a link does not say stays as it was. Changing an option does not rewrite the location (there is no address bar), and an account keeps its own period (`scopePreset`), so `p` / `start` / `end` are not read there | `filters.store.ts`, the `filters.param` reads of each view-model |
| Chart as table / export | chart card: table toggle, PNG download | `ChartCard`: a button swaps the chart for its table and another shares that table as CSV (disabled while amounts are hidden); the PNG download is web-only (the share sheet takes the CSV instead). Charts without a table on the web (net worth by account, savings rate, running balance, compare trend, ranking trend) have none here either | `chart-table.ts`, the `*Table` of each view-model |
| About | `/about` | `/about` (from the More tab: versions, Firefly compatibility, primary currency, signed-in user) | `meta.store.ts` |
